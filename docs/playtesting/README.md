# Playtesting

Each round gets its own folder: `round-1/`, `round-2/`. Put the questionnaire results, observation notes and screenshots there, with tester names removed.

| Round | Date | Build (commit) | Testers | Focus |
| --- | --- | --- | --- | --- |
| 1 | 29 Oct 2026 (lab) | | | Is the core loop clear? Is the oil and clock pressure fair? |
| 2 | 2 Nov 2026 | | | Moth behaviour, difficulty across 3 districts, controls |

Every finding that leads to a change becomes a GitHub Issue, and the fixing commit closes it (`Fixes #12`). That is the link markers look for between feedback and development.
